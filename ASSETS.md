## Photos: slots wired, files pending

Every photo slot is already wired with a file name, alt text, crop focus (`position`) and a responsive `sizes` hint.
Until a file is processed, the slot shows its labelled placeholder, so nothing breaks.

**Chosen source: AI-generated images (Canva "generate image").** Generation works, but the connector only returns 133 px previews.
Exporting at full resolution failed because the Canva credit cooldown was active.

**To finish:**

1. Generate each image below in Canva using the given prompt and aspect ratio, or reuse the hero image already generated: Canva media `MAHcFXeii-E`, 1664×2496.
2. Download it at full size and save it as `assets-src/photos/<file name>.jpg` (PNG and WebP also work).
3. Run `npm run images`. This writes AVIF, WebP and JPEG variants at 400, 800, 1200 and 1600 px to `public/images/photos/` and updates `src/content/image-manifest.ts`.
4. Run `npm run build`. Each photo appears in its slot automatically.

Shared style suffix for every prompt, to keep lighting and colour consistent:
*"editorial lifestyle photography, soft natural window light, warm muted earthy tones, gentle film grain, shallow depth of field, authentic and calm, South Asian subjects, no text, no logos, high resolution"*

## Intentional gaps

- **Press logos ("Featured By", Home):** only real coverage can go here. Add the logos in `src/content/home.ts`, or empty the array to hide the band.
- **Team portraits and Founder's Note:** use authentic photos when available (put them in `assets-src/photos/`, run `npm run images`, set `src` and `alt` to the person's name). Do not substitute stock or AI people.
- **Contact Us:** the approved design has no image area. Contact icons already use the site's Lucide set. A map or premises photo was not added because there is no verified address yet.
- **Phone mock-ups** (Home "How it works", Services "beginning to end") are illustrative CSS UI and need no image files.
